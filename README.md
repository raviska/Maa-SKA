# MAAI: Heal The Mother Earth Save Carbon

Expo SDK 57 mobile prototype.

App name:
MAAI: Heal The Mother Earth Save Carbon

Includes:
- AI workload carbon/energy estimate
- Water estimate (clearly labelled illustrative)
- AI session counter
- QR scanner using expo-camera
- MAAI visual dashboard

SDK:
- Expo SDK 57
- React Native 0.86
- React 19.2.3
- expo-camera ~57.0.5

The estimates are prototype assumptions. A production implementation should connect
measured telemetry and a documented carbon-intensity methodology.
